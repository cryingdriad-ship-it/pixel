# Pixel Diff Viewer

Вебзастосунок для попіксельного порівняння двох зображень прямо в браузері (без сервера та без зовнішніх бібліотек).

## Що робить застосунок

1. **Завантаження**: користувач обирає зображення-оригінал (`Base`) і тестове зображення (`Test`).
2. **Аналіз**: для кожного пікселя на однакових координатах порівнюються канали `RGBA`.
3. **Diff-карта**:
   - пікселі, що збігаються, відображаються приглушено (напівпрозорий grayscale),
   - пікселі з відмінностями підсвічуються яскравим кольором.
4. **Статистика**: показуються:
   - точна кількість пікселів із відмінностями,
   - відсоток відмінностей від загальної кількості пікселів.

## Реалізований обов'язковий функціонал

- **Поріг чутливості (Threshold / Tolerance)** від `0` до `255`.
- **Режими перегляду**:
  - одночасний показ **оригіналу, тесту й diff** на одному екрані,
  - `Overlay` — накладання з керуванням прозорістю верхнього шару,
  - `Slider` — шторка (перетягування мишею по зображенню).
- **Перевірка розміру**: попіксельне порівняння виконується лише тоді, коли розміри зображень збігаються.

## Як запустити

Оскільки це повністю клієнтський застосунок, достатньо відкрити `index.html` у браузері.

Альтернативно можна запустити локальний статичний сервер, наприклад:

```bash
python3 -m http.server 8080
```

І відкрити:

```
http://localhost:8080
```
