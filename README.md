# Pixel Diff Viewer

Веб-приложение для попиксельного сравнения двух изображений прямо в браузере (без сервера и без внешних библиотек).

## Что делает приложение

1. **Загрузка**: пользователь выбирает изображение-оригинал (`Base`) и тестовое изображение (`Test`).
2. **Анализ**: для каждого пикселя на одинаковых координатах сравниваются каналы `RGBA`.
3. **Diff-карта**:
   - совпадающие пиксели отображаются приглушенно (полупрозрачный grayscale),
   - различающиеся пиксели подсвечиваются ярким цветом.
4. **Статистика**: показываются:
   - точное количество несовпадающих пикселей,
   - процент отличий от общего числа пикселей.

## Обязательный функционал, который реализован

- **Порог чувствительности (Threshold / Tolerance)** от `0` до `255`.
- **Режимы просмотра**:
  - `Side-by-side` — изображения рядом,
  - `Overlay` — наложение с управлением прозрачностью верхнего слоя,
  - `Slider` — шторка (перетаскивание мышью по изображению).
- **Проверка размера**: попиксельное сравнение выполняется только если размеры изображений совпадают.

## Как запустить

Так как это полностью клиентское приложение, достаточно открыть `index.html` в браузере.

Альтернативно можно запустить локальный статический сервер, например:

```bash
python3 -m http.server 8080
```

И открыть:

```
http://localhost:8080
```
